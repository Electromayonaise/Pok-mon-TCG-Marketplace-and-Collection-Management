The mocks are illustrative. The page specs in C-UX-Scenarios and the spines (DESIGN.md, EXPERIENCE.md) win on any conflict. All Spanish copy comes from the page specs or microcopy-es-CO.md. Values the specs leave open stay as {placeholders}. Mock notes in English (dashed boxes) mark illustrative fixture data and the points where a spec is ambiguous.

Every other page is specified by its spec's ASCII layout and state table.

How the mocks are built

  • _tokens.css holds the DESIGN.md tokens (flat surfaces, no shadows) and the component classes the mocks share.
  • _states.js builds the state selector. Each data-state block is one row of the spec's Page States table. A block shared by several states lists the other states in data-also. data-default picks the state that opens first.
  • The frame widths are R 400 px (1120 px for two-pane pages), D with the admin rail, and H at 1280 px.
