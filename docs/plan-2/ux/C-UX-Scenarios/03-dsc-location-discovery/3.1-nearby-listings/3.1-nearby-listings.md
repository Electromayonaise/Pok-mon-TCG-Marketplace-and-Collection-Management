## Overview

**Page Purpose:** Answer "who sells this near me?" with one mixed list of individual and business listings inside a radius, ranked deterministically, with every row explained (FR-DSC-1..6).

**Success Criteria:**
- Distances are shown to 0.1 km, and the boundary is inclusive.
- Exclusions for an unusable location are counted in a footer.
- Pickup and purchasability are correct on every load.
- An identical query gives an identical order.

**Entry Points:** Bottom bar → Cerca de ti; "Ver todas" in 2.2 (pre-filtered to one entry).

**Exit Points:** 2.2 (tap a row or entry); 6.1 (Comprar); 12.1 (Contactar al vendedor); 8.1 (Hacer una oferta).

## Page Sections

### Section: Area Control

**OBJECT ID:** `dsc-nearby-area`

| Property | Value |
|----------|-------|
| Component | [`components.location-picker`](../../../DESIGN.md) in a sheet: "Usar mi ubicación" (browser geolocation) · "Elegir ciudad" (a list of the capitals plus a draggable point on a static map image) · radius slider plus numeric input, 1–300 km (default 15) |
| Validation | Outside Colombia, or a radius outside 1–300: `field-error` "Elige un punto dentro de Colombia y una distancia entre 1 y 300 km." (`InvalidSearchArea`). The search doesn't run |
| Geolocation denied | "No pudimos usar tu ubicación. Elige tu ciudad." The picker stays open; there is no dead end |
| No area | "Todo el país" option. Rows show no distance and are ordered by price; rows with an unusable location appear last as "sin ubicación" (FR-DSC-3) |
| Persistence | Point and radius are in the URL (`?lat=&lng=&r=`) plus a per-device preference. Coordinates are rounded to 3 decimals (≈110 m) in the URL for privacy |

### Section: View Switch and Filters

**OBJECT ID:** `dsc-nearby-filters`

| Property | Value |
|----------|-------|
| View | Radio "Cartas" (`view=entries`: one tile per card with its top listings plus "y {n} más") / "Publicaciones" (`view=listings`: flat rows) |
| Filters | Catalog filters (as in 2.1), plus "Precio máximo", "Estado de la carta" (condition[]), and "Solo comprables" (`purchasableOnly`). "Mostrar agotadas" is off by default |

### Section: Result Rows

**OBJECT ID:** `dsc-nearby-rows`

| Property | Value |
|----------|-------|
| Component | `listing-card` plus [`components.distance-row-explanation`](../../../DESIGN.md) |
| Explanation | Typed parts from the API, rendered in order: distance · seller mode (pickup / verified / unverified) · state (purchasable / paused / sold out) |
| Actions | Same rules as 2.2 `cat-detail-listings`: Comprar only when purchasable; no disabled buy buttons; paused and unverified rows offer "Escribir a la tienda" |
| Sold out (when shown) | Rows last, "agotada", no actions except "Agregar a lista de deseos" |
| Entries view | Tile: card image, name, "{n} a la venta cerca · desde $88.000", then up to 5 compact rows, then "Ver las {moreCount} restantes" → 2.2 |

### Section: Ordering Disclosure

**OBJECT ID:** `dsc-nearby-ordering`

| Property | Value |
|----------|-------|
| Component | `<details>` "Cómo ordenamos" |
| Copy | With an area: "Primero la más cercana; si están a la misma distancia, la más barata; si también cuestan lo mismo, siempre en el mismo orden fijo." Without an area: "Primero la más barata; si cuestan lo mismo, siempre en el mismo orden fijo." Plus "No hay resultados patrocinados." |

### Section: Exclusion Footer

**OBJECT ID:** `dsc-nearby-excluded`

| Property | Value |
|----------|-------|
| Content | When `excluded.unusableLocation > 0`: "{n} publicaciones no aparecen porque no tienen una ubicación válida." (`ListingLocationUnusable`). Hidden, withdrawn and deactivated listings are never counted or mentioned to buyers |

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| First visit | No area chosen | Area sheet open, with "Usar mi ubicación" as primary; "Ver todo el país" as secondary | Choose |
| Loading | Query | Area line plus 4 row skeletons | — |
| Empty (zero results) | Nothing within the radius | "Ninguna publicación coincide con estos filtros dentro de {radio} km." | "Quitar filtros" / "Ampliar a {radio×2} km" (capped at 300) |
| Filter too broad | `SearchFilterTooBroad` (AD-DSC-2): the catalog filters match too many cards to search listings | Banner "Estos filtros incluyen demasiadas cartas para buscar publicaciones. Elige una expansión, un tipo o un nombre para acotar la búsqueda."; filter controls stay open and focus moves to the banner; no result list | Adjust filters |
| Error | Fetch failed | Banner plus Reintentar; previous results cleared (no stale list) | Reintentar |
| Success | Results | Rows plus count plus footer | As above |

## Technical Notes

- One `listings.browse` call per render. The UI never merges two calls by seller kind (AD-5).
- No client-side re-sorting. The API order is authoritative (FR-DSC-5), so "Cargar más" appends pages without re-ranking.
- Nothing is cached across navigations; returning to the page re-queries (FR-DSC-6).
- Distance is shown with a comma decimal ("a 12,4 km") per ADD-§2.7.
