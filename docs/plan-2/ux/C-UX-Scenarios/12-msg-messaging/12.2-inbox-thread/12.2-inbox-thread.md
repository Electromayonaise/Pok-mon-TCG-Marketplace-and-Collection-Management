## Overview

**Page Purpose:** Let a buyer and a shop talk inside TEZG, and always make clear three things: whether the shop is verified, what is still unread, and when the thread can no longer take messages.

**Success Criteria:**
- A Pending shop's status is stated in the composer and on every message sent while it was Pending; a notice is never removed from a message later.
- Unread counts match the thread: opening it sets the reader's count to 0, and the count never goes back up for messages already seen.
- A send that fails keeps the typed text; nothing the buyer wrote is lost.
- New messages appear without a reload within one polling interval (30 s).

**Entry Points:** Actividad → Mensajes; "Escribir a la tienda" on 2.2, 3.1, 6.1 (`ListingNotPurchasable`), 6.2 (expired and stalled states, `ComprobanteLocked`) and 12.1 (`NotIndividualSellerListing`); a thread deep link.

**Exit Points:** The listing in context (2.2, "Ver publicación"); the shop's profile (11.2); 12.1 (`NotBusinessAccount` with a listing in context).

## Technical Notes

- Polling (NFR-MSG-2, EXPERIENCE): the inbox and the open thread poll every 30 s while visible, pause when the tab is hidden and refetch on focus. The thread poll asks only for messages after the newest one held.
- The composer receives the shop's eligibility when it opens and shows the notice from it, but the server decides at send time (FR-MSG-5). The response carries the current state, so the notice banner appears or disappears on the reply to the send.
- Idempotent send: the client sends a message id generated when "Enviar" is first pressed and reuses it on retry, so a retry after a lost response cannot create two messages. Phase 3 names the key.
- `/mensajes/nueva` checks for an existing conversation for the pair and redirects to it (conversation unique per pair, FR-MSG-5); the conversation row is created with the first message, never by opening the page.
- A-38: admins have no route to message bodies; the admin view of a thread id is the Not-available page.
- **Silenciar conversación** (FR-MSG-8, adopted at the Phase 2 gate): buyer-side toggle in the thread menu. New messages still arrive, but the thread leaves the unread badge and moves to "Silenciadas". The shop is not told. "Dejar de silenciar" reverses it. See EXPERIENCE, Messaging Safety.
