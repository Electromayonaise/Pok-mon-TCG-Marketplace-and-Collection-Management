## Overview

**Page Purpose:** Give a buyer a correct, ready-to-send message about an individual seller's listing and hand it to WhatsApp or the clipboard. TEZG sends nothing itself and never prints the seller's phone.

**Success Criteria:**
- The preview is exactly the text WhatsApp will receive: same characters, same price with "COP".
- "Copiar mensaje" always copies the full text, even when the WhatsApp text had to shorten a name, and the page says so when that happens.
- A refused caller (not signed in, unverified email, rate limit, gone or shop listing) sees why, and never a composer they can't use.

**Entry Points:** "Contactar al vendedor" on an individual seller's row in 2.2 and 3.1; the `NotBusinessListing` banner on 6.1; the `NotBusinessAccount` action on 12.2 when a listing is in context.

**Exit Points:** WhatsApp (new tab or app); back to the page it came from; 2.2 ("Buscar otra publicación de esta carta" on `ListingNotFound`); 6.1 / 12.2 (the actions on `NotIndividualSellerListing`).

## Page Sections

### Section: Listing Summary

**OBJECT ID:** `msg-contact-listing`

| Property | Value |
|----------|-------|
| Back link | "← {producto}" → the page it came from |
| Heading | "Contactar a {vendedor}" |
| Summary | Compact `listing-card`: product, condition, `{precio}`, "Vende una persona · a {distancia}" (distance only when the caller has a location set) |

### Section: Message Preview

**OBJECT ID:** `msg-contact-preview`

| Property | Value |
|----------|-------|
| Component | `contact-composer.preview-frame` |
| Text | The service's `text`, rendered as plain text: a URL-like substring in a name is never turned into a link, and no markup is interpreted (FR-MSG-2) |
| Editable | No. The note "Se abrirá WhatsApp con este mensaje. Puedes editarlo allí antes de enviarlo." explains where to change it. Editing here would break the preview = link guarantee |
| Shortened note | When `text` ≠ `copyText` (a long name was shortened for the link): "El mensaje para WhatsApp acorta el nombre de la carta. «Copiar mensaje» copia el texto completo." (trade variant on 8.2: "…acorta los nombres de las cartas…") |
| Accessible name | The preview is a `blockquote` labelled "Tu mensaje"; screen readers read it once, in full |

### Section: Actions

**OBJECT ID:** `msg-contact-actions`

| Property | Value |
|----------|-------|
| Open | `button-primary` "Abrir WhatsApp": a link (`<a>`) to `externalUrl`, `target="_blank"`, `rel="noopener noreferrer"`. The URL is never shown as text, and the phone never appears elsewhere on the page |
| Copy | `button-secondary` "Copiar mensaje": copies `copyText`; the live region says "Copiado". If the clipboard is blocked: "No pudimos copiar. Selecciona el texto del mensaje y cópialo." and the preview text becomes selected |
| Footer note | "TEZG no envía este mensaje ni participa en la conversación. El pago y la entrega se acuerdan entre ustedes." |

### Section: Refusal Banner

**OBJECT ID:** `msg-contact-refusal`

| Decision | Banner (replaces preview and actions) | Action |
|----------|----------------------------------------|--------|
| `NotAuthenticated` | Redirect to sign-in; §1 copy on the sign-in page | Returns to 12.1 |
| `EmailNotVerified` | §1: "Para comprar, ofertar o escribir a vendedores, primero confirma tu correo. Te enviamos un enlace a {correo}." | Reenviar enlace |
| `ContactRateLimited` (per requester or per IP) | §3: "Enviaste muchos mensajes de contacto seguidos. Podrás contactar a más vendedores a las {hora}." | — |
| `ContactRateLimited` (per seller, per day) | §7: "Ya contactaste a {vendedor} varias veces hoy. Podrás volver a escribirle desde el {fecha}." | — |
| `ListingNotFound` | §3: "Esta publicación ya no está disponible." | Buscar otra publicación de esta carta |
| `NotIndividualSellerListing` | §3: "Esta carta la vende una tienda: puedes comprarla aquí mismo o escribirle dentro de TEZG." | Comprar (6.1), Escribir a la tienda (12.2) |

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Loading | The generation call is in flight | `skeleton` summary and preview | — |
| Empty | Not applicable | The page always shows a generated message or a refusal; there is no list | — |
| Default | Text generated | Summary, preview, notes, both buttons | Abrir WhatsApp, Copiar mensaje |
| Shortened | `text` ≠ `copyText` | Default plus the shortened note | Same |
| Copied | "Copiar mensaje" succeeded | Live region "Copiado"; nothing else changes | — |
| Refused | Any Decision in the refusal table | Banner in place of preview and actions; the summary stays when the listing still resolves | Per banner |
| Error — network | Generation did not complete | §10 load copy ("No pudimos cargar el mensaje…") | Reintentar |

There is no success state beyond "Copiado": TEZG cannot know whether the buyer sent the message in WhatsApp, and the page does not pretend to.

## Technical Notes

- One call to `listings.generateContactMessage({ kind: 'purchase', listingId, requesterId })` on page load. The page renders `text`, links `externalUrl` and copies `copyText` exactly as returned; the browser never formats, truncates or encodes anything (FR-MSG-2 determinism lives on the server).
- Each generation counts as one contact request for the FR-MSG-3 limits. A reload generates again and counts again [ASSUMPTION: the PRD counts contact messages, not distinct listings; Phase 3 may de-duplicate per requester and listing within the hour. Logged in `review-ux-edge-cases.md`].
- `externalUrl` is placed only in the `href` of the "Abrir WhatsApp" link. It is not written to analytics, client logs or error reports (FR-MSG-3: phones never logged).
- NFR-MSG-3: the page and the server make no request to WhatsApp; opening the link is the buyer's own navigation. 12.3 counts outbound calls through the external-app stub.
- WhatsApp is the launch channel [ASSUMPTION A-34]; the template is channel-agnostic, so only the button label and the URL builder would change for another channel.
