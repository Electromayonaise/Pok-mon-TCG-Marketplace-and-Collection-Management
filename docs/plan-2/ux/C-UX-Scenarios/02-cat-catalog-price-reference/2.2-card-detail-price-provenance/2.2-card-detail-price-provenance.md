## Overview

**Page Purpose:** Show one catalog entry with three distinct, labelled prices and their provenance (FR-CAT-6), plus the ranked listings for it (FR-DSC-7). Each listing offers the action its seller kind supports:
- Comprar (business, purchasable);
- Contactar al vendedor (individual);
- Hacer una oferta (individual, open to trade).

**Success Criteria:**
- Exactly three price blocks, each with a label and a provenance line; never merged.
- A stale price is labelled with its date.
- An entry with no listings, or none nearby, says so and still renders.

**Entry Points:** 2.1, 3.1, 9.1 (a binder pocket), 9.3, `/c/<catalogEntryId>` deep links.

**Exit Points:** 6.1 (Comprar), 12.1 (Contactar al vendedor), 8.1 (Hacer una oferta), 12.2 (Escribir a la tienda), 9.3 (Agregar a lista de deseos), 9.2 (Agregar a mi colección), 11.2 (seller name).

### Section: Listing Price Block

**OBJECT ID:** `cat-detail-price-listing`

| Property | Value |
|----------|-------|
| Component | [`components.price-provenance-block`](../../../DESIGN.md) variant `listing` |
| Content | The lowest active listing (purchasable or contactable) in COP plus a count. None: "Nadie la está vendiendo ahora." |
| Scope note | When an area is active, the note reads "en todo el país"; the lowest price is nationwide, while the listings block below is area-filtered |

### Section: Reference Price Block

**OBJECT ID:** `cat-detail-price-reference`

| Property | Value |
|----------|-------|
| Component | `price-provenance-block` variant `reference` plus [`components.stale-label`](../../../DESIGN.md) |
| Content | "US$41,20 · $169.886 COP", then provenance "TRM al 30 sep 2026 · {fuente} · 30 sep". When `copDerivation='sourceNative'`, no TRM line is shown |
| Stale | "◷ Precio del {día}: el feed no se actualiza desde entonces." The old value stays visible |
| TRM carried forward | Appends "(no hay una TRM publicada para la fecha)" |
| Unpriced | "Aún no hay precio de referencia." and no figure |

### Section: Trend Block

**OBJECT ID:** `cat-detail-price-trend`

| Property | Value |
|----------|-------|
| Component | `price-provenance-block` variant `trend`, plus a 7/30/90 segmented control (radio group) |
| Content | "+8,41 % en 30 días · desde $156.700". The sign uses U+2212 for negatives; `trend-positive` / `trend-negative` colour plus an ▲/▼ glyph plus the sign |
| No baseline | "Sin tendencia: no hay precio de referencia al inicio del período." (`TrendNoBaseline`) |
| Provenance toggle | "¿De dónde salen estos precios?" `<details>`: "Los precios de referencia vienen del feed externo del catálogo, no de las ventas en TEZG. La conversión a pesos usa la TRM oficial del día de la observación." |

### Section: Listings Block (DSC)

**OBJECT ID:** `cat-detail-listings`

| Property | Value |
|----------|-------|
| Component | `listing-card` rows with [`components.distance-row-explanation`](../../../DESIGN.md) |
| Area control | "Cerca de: {ciudad}, {radio} km · Cambiar" opens the location picker (same as 3.1). With no area, rows show no distance and the order is by price |
| Ranking | FR-DSC-5; top 5 plus "Ver todas" (→ 3.1 filtered to this entry) |
| Actions per row | Business, purchasable: "Comprar" (primary) plus "Escribir a la tienda". Business, not purchasable: the reason line from microcopy §3 plus "Escribir a la tienda" (no disabled Comprar). Individual: "Contactar al vendedor", plus "Hacer una oferta" when `openToTrade` |
| Own listing | "Es tu publicación" plus "Editar" (no buy or offer) |
| None nearby | "Nadie la vende a menos de {radio} km." plus "Ampliar a {radio×2} km" / "Ver en todo el país". The entry still renders (FR-DSC-7) |
| None at all | "Nadie la está vendiendo ahora. Puedes agregarla a tu lista de deseos." plus the "Agregar a lista de deseos" action |

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Loading | Fetch | Header plus three block skeletons plus 2 row skeletons | — |
| Empty | The entry has no reference price and no active listings | The card still renders: the "Success — unpriced" and "Success — no listings" rows below apply together ("Aún no hay precio de referencia." and "Nadie la está vendiendo ahora.") | Agregar a lista de deseos |
| Not available | `CatalogEntryNotFound` | Standard Not-available page: "No encontramos esta carta en el catálogo." | Volver al catálogo |
| Error | Fetch failed | Banner with "Reintentar". If only the provenance failed, the three blocks show "No pudimos cargar el precio de referencia." while the listings still render | Reintentar |
| Success — fresh | Normal | As in the layout | Buy / contact / offer |
| Success — stale | `ReferencePriceStale` | Stale label on the reference block | — |
| Success — unpriced | No observations | Reference and trend show "Aún no hay precio de referencia." | — |
| Success — no listings | `hasActiveListings=false` | Listing price block: "Nadie la está vendiendo ahora." Listings block empty-state | Wishlist |
| Lost race (from 6.1) | Returned with `InsufficientQuantity` | Banner at the top: "Otra persona reservó la última unidad hace un momento…"; list re-fetched | "Buscar otra publicación de esta carta" (scrolls to the listings) |

## Technical Notes

- Composition via `listings.getCardDetail` (FR-DSC-7) keeps the AD-1 edge `listings → catalog`.
- The three blocks are separate components with separate labels. There is no "market price" summary anywhere (FR-CAT-6).
- The poll-free page refreshes when it regains focus after more than 60 s, so a paused or withdrawn listing doesn't linger. It shows no live countdowns (UX-D-9).
