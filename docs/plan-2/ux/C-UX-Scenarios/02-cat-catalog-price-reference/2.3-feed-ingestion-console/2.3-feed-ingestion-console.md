## Overview

**Page Purpose:** Start and monitor feed runs, audit their counts, inspect quarantined rows by reason, confirm that attribute changes kept each entry's identity, and watch TRM freshness (FR-CAT-3, FR-CAT-4, FR-CAT-7, FR-CAT-8).

**Success Criteria:** Counts add up to the rows in the file. A rerun shows convergence. A concurrent start is refused with an explanation. Every quarantined row shows its reason and raw content.

**Entry Points:** Admin rail → Catálogo; the daily-alert link (a failed scheduled run).

**Exit Points:** 2.2 (from a revision row, "Ver carta").

## Page Sections

### Section: Run Control

**OBJECT ID:** `cat-ingest-control`

| Property | Value |
|----------|-------|
| Component | File `<select>` (files staged by the feed port; no browser upload in V1) plus `button-primary` "Iniciar ingesta" |
| Behavior | Starting a run writes an audit row (NFR-SYS-8). If a run is in progress, the button is replaced by the banner "Ya hay una ingesta en curso (iniciada el {fecha}). Espere a que termine para iniciar otra." plus "Ver ingesta en curso" (`FeedRunInProgress`) |
| Progress | `role="progressbar"` with "6.420 / 10.000 filas", announced politely every 25 % |

### Section: Runs Tab

**OBJECT ID:** `cat-ingest-runs`

| Property | Value |
|----------|-------|
| Component | [`components.data-table`](../../../DESIGN.md), 25 per page, newest first |
| Columns | Run · started by (admin name or "Programada") · start → end · Creadas · Actualizadas · Sin cambios · Cuarentena · result |
| Result words | "Completa" / "Interrumpida: los lotes ya confirmados son válidos; vuelva a ejecutar para completar" / "Converge con la ejecución anterior" |
| Integrity check | If created + updated + unchanged + quarantined ≠ the file's rows: "Los conteos no suman las filas del archivo" in `status-error` text |

### Section: Quarantine Tab

**OBJECT ID:** `cat-ingest-quarantine`

| Property | Value |
|----------|-------|
| Component | `data-table`, filter chips per reason (the 5 ADD-§8.1 kinds, each with its count) |
| Columns | Row # · `externalKey` (if parseable) · reason in words plus code · run |
| Row expand | Raw row in `typography.code`, read-only; "Copiar fila" |
| Note | "Las filas en cuarentena no se aplicaron. Corríjalas en el feed de origen y vuelva a ejecutar." |

### Section: Revisions Tab

**OBJECT ID:** `cat-ingest-revisions`

| Property | Value |
|----------|-------|
| Component | `data-table` |
| Columns | Entry (name plus `catalogEntryId`) · changed fields · before → after · run |
| Proof line | "El id de la carta no cambió: publicaciones, colecciones y listas de deseos siguen enlazadas." Each row links to 2.2 |

### Section: TRM Tab

**OBJECT ID:** `cat-ingest-trm`

| Property | Value |
|----------|-------|
| Content | Today's rate (e.g. "$4.123,45 por US$1 · vigente 1 oct 2026 · datos.gov.co"), the last fetch attempt, and the next scheduled attempt (hourly 07:00–20:00 Bogotá) |
| Carried forward | "Sin TRM para hoy: usamos la del {día}." in `status-pending` plus words |

### Section: Fault Switch (H only)

**OBJECT ID:** `cat-ingest-fault-switch`

| Property | Value |
|----------|-------|
| Component | Radio group: normal · down · stale · malformedRows · renamedRows; plus a virtual-clock control |
| Visibility | Rendered only in non-production builds, inside a dashed panel titled "Simulador de fallas (solo datos de prueba)" |

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Loading | Fetch runs | Table skeleton | — |
| Empty | No runs yet | "Aún no hay ejecuciones. Inicie la primera ingesta para cargar el catálogo." | Iniciar ingesta |
| Error | Fetch failed | Banner plus Reintentar | Reintentar |
| Running | A run is in progress | Progress row; start refused as above | Ver ingesta en curso |
| Success | Run finished | Summary row; live-region confirmation "Ingesta completa: 9.950 creadas, 50 en cuarentena." | Open tabs |
| Interrupted | Crash mid-run | Row result "Interrumpida…" | Iniciar ingesta (rerun converges) |
| Stale feed | Last success > 36 h ago | Header "Última ejecución correcta hace 40 h: los precios se muestran como desactualizados." | — |

---

## Technical Notes

- Scheduled and manual runs share the lock (`FeedRunInProgress`).
- The page polls every 5 s while a run is active, and every 30 s otherwise.
- Quarantine counts come from `QuarantinedFeedRow`; nothing is ever partially applied (FR-CAT-3).
