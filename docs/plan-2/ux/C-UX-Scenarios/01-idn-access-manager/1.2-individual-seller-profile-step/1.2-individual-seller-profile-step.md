## Overview

**Page Purpose:** Collect the minimum an individual seller needs, then return the person to what they were doing:
- a display name;
- a contact phone with sharing consent;
- a default meeting point.

(FR-IDN-2.)

**Success Criteria:** One submit completes the step, `canListAsIndividual` becomes true, and the person lands back on the listing draft (4.1) or on Cuenta.

**Entry Points:**
- 4.1 banner "Completar perfil" (`?returnTo=/vender/nueva`);
- Cuenta → Vender → "Vender como persona";
- 8.x / 12.x never link here.

**Exit Points:** the `returnTo` target (a same-origin path only); Cuenta.

## Page Sections

### Section: Display Name

**OBJECT ID:** `idn-profile-display-name`

| Property | Value |
|----------|-------|
| Component | Text input, `autocomplete="nickname"` |
| Validation | 2–40 characters, counted as graphemes (emoji = 1) |
| Error copy | "Escribe entre 2 y 40 caracteres." |

### Section: Contact Phone & Consent

**OBJECT ID:** `idn-profile-phone`

| Property | Value |
|----------|-------|
| Component | Fixed "+57" prefix plus a `type="tel"` input, `inputmode="numeric"` |
| Validation | 10 digits starting with 3. Spaces are tolerated on input and stripped before submit |
| Error copy | "Escribe un celular colombiano de 10 dígitos que empiece por 3." |
| Consent | Required checkbox (`phoneSharingConsent`). Copy: "Acepto que mi número se use solo en el enlace de contacto con compradores." Error if unchecked: "Para vender como persona necesitamos tu autorización para compartir tu número en el enlace de contacto." Link: "Ver aviso de privacidad" (opens in a new tab) |
| Note | The number is never shown on public pages; it appears only inside the generated `wa.me` link (FR-MSG-3) |

### Section: Meeting Point

**OBJECT ID:** `idn-profile-meeting-point`

| Property | Value |
|----------|-------|
| Component | [`components.location-picker`](../../../DESIGN.md) plus a city-label input |
| Behavior | "Usar mi ubicación" requests browser geolocation. If denied, it falls back to the city `<select>` (department capitals, with their centroids). A point outside the Colombia box → `InvalidLocation` field error |
| Validation | City label 2–60 characters: "Escribe el nombre del lugar (2 a 60 caracteres)." |
| Privacy note | "Mostramos la distancia aproximada, no tu dirección." |

### Section: Submit

**OBJECT ID:** `idn-profile-submit`

| Property | Value |
|----------|-------|
| Component | `button-primary`, full width on mobile |
| Content | "Guardar y volver a mi publicación" when `returnTo` is a listing draft; otherwise "Guardar perfil" |
| Behavior | Disabled synchronously on press. Shape errors come back all at once: a summary "Revisa 2 campos antes de continuar:" linking to each field, with focus moving to the summary |

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Loading | Initial eligibility fetch | Form `components.skeleton` | — |
| Empty | Not applicable | A form has no list that could be empty; the blank form is the default state below | — |
| Editing | `sellerKind='none'` | Form as above | Fill, submit |
| Field errors | `RequestValidationFailed` | Summary plus inline `field-error`s; values kept | Fix, resubmit |
| Error (transport) | Network or 5xx | Banner "No sabemos si tu perfil se guardó porque se perdió la conexión. Actualiza para ver el estado actual; si no se guardó, puedes repetirlo sin riesgo." | Actualizar |
| Success | Profile written | Redirect to `returnTo` with the polite live-region confirmation "Perfil guardado. Ya puedes publicar." | — |
| Refused — already complete | `IndividualSellerProfileAlreadyComplete` | Banner (microcopy §1) instead of the form | "Ir a Cuenta" |
| Refused — application on file | `BusinessApplicationOnFile` | Refusal banner instead of the form; "¿Por qué?" expands the rule (one seller type per account) | "Ver solicitud" → 5.2 |
| Refused — verified business | `AlreadyVerifiedBusiness` | Refusal banner | "Ir a Mi tienda" |
| Lost race | Submit returns `BusinessApplicationOnFile` after the form was shown | Re-fetch; the form is replaced by the refusal banner. The typed values are discarded, because they no longer apply | "Ver solicitud" |

## Technical Notes

- `returnTo` accepts only same-origin relative paths (no open redirect). The 4.1 draft is stored client-side (sessionStorage) by 4.1, not by this page.
- Rules 1–3 are re-checked at write time (FR-IDN-4). The page never assumes its initial eligibility read is still true.
- Consent is stored with `phoneSharingConsentAt` and `phoneSharingConsentVersion`. The version shown next to the privacy-notice link is the one sent.
