## Overview

**Page Purpose:** Show how the value of the collector's *current* cards moved day by day, with each acquisition as a visible step and each carried-forward price marked, as a chart and as a table carrying exactly the same data.

**Success Criteria:**
- One point per calendar day (`America/Bogota`), every value in whole pesos.
- The chart is readable without sight: a summary sentence, keyboard-focusable points and "Ver como tabla".
- Stale points are marked by line style and words, never by colour alone.
- The heading states that the series is recomputed from the current cards.

**Entry Points:** 10.1 "Ver historial" (same collection and period); UJ-5 step 3.

**Exit Points:** 10.1 ("← Valor", keeping the collection and period).

## Page Sections

### Section: Header and Controls

**OBJECT ID:** `val-history-header`

| Property | Value |
|----------|-------|
| Heading | "Lo que valían tus cartas actuales" + note "Si quitas una carta, también sale del cálculo de fechas anteriores." |
| Colección / period | Same controls and URL parameters as 10.1; the period sets the visible window of the series |

### Section: Chart

**OBJECT ID:** `val-history-chart`

| Property | Value |
|----------|-------|
| Component | `valuation-chart`: 2 px line, no area fill, no gradient |
| Range | Daily points from `max(earliest acquisition date, asOf − 365 days)` to `asOf`; the period chip shows the last 7, 30, 90 or 365 days of that series (or the whole series if shorter) |
| Stale points | A point whose value carries a price forward is drawn as a dashed segment (`valuation-chart.stale-segment`), with the legend "┄┄ Precio sin actualizar" |
| Steps | A priced entry acquired inside the window rises the line on its acquisition date |
| Point focus | Each point is focusable (arrow keys move along the line). The tooltip, also announced: "{dia} · {valor}"; plus "+{valor} por cartas nuevas ese día" on a step; plus "◷ Incluye 1 precio sin actualizar desde el {dia}" (plural: "◷ Incluye {n} precios sin actualizar; el más antiguo es del {dia}") on a stale point |
| Accessible name | The SVG has `role="img"` and the summary sentence as its name |
| Summary sentence | Shown under the chart: "Valor entre el {inicio} y el {fin}: de {valor inicial} a {valor final}, {cambio}". `{cambio}` is the 10.1 change for the same period ("+5,69 %"), or "Nuevo en este período" on a zero baseline |
| Axis | Labels thin out on long ranges; points never do |

### Section: Table View

**OBJECT ID:** `val-history-table`

| Property | Value |
|----------|-------|
| Toggle | "Ver como tabla" / "Ver como gráfico"; the choice is kept for the session |
| Component | `data-table` (stacked rows below 768 px) |
| Columns | Fecha · Valor · Cambio (from the previous day; "—" on the first row) · Nota |
| Notes | "Cartas nuevas: {cartas}" on a step day (at most 3 names, then "+{n} más") · "Precio sin actualizar: {cartas}" on a stale day |
| Order and paging | Newest first; 31 rows per page with "Ver más" |

## Technical Notes

- The series is recomputed from the current entries on every request (FR-VAL-4), so removing, moving or deleting an entry removes its contribution from every past point. The heading says so, as does the trend note on 10.1.
- The whole series (≤ 366 points) comes in one response; the period chips slice it in the browser, and the summary's percentage comes from the same FR-VAL-2 call as 10.1, never from browser arithmetic.
- A point is marked stale when any price in it is carried forward from an earlier day (FR-VAL-4); the stale threshold for the current price is the catalog's (FR-CAT-7).
- NFR-VAL-2: 365-day history for 500 entries, p95 ≤ 2.500 ms.
