## Overview

**Page Purpose:** Tell the collector what one collection is worth today in whole pesos, how that changed over a chosen period, which cards the total leaves out and why, and which prices are stale, with a per-card breakdown that adds up to the total.

**Success Criteria:**
- The headline total equals the sum of the breakdown rows, shown in the table footer.
- Every card is either in the total or in "No valoradas" with its reason; the page says both counts.
- A zero baseline shows the change in pesos and "Nuevo en este período", never a broken percentage.
- No USD figure is ever added into a peso figure.

**Entry Points:** Mi colección tab "Valor"; 9.1 back link; UJ-5 step 2.

**Exit Points:** 10.2 ("Ver historial"); 2.2 (a card's name in the breakdown or the unpriced group); 9.1 and 9.3 (tabs); the external link of a link-added entry (new tab).

## Page Sections

### Section: Controls

**OBJECT ID:** `val-value-controls`

| Property | Value |
|----------|-------|
| Colección | Native select of the owner's collections; default: the most recently opened. Valuation is always per collection |
| Period | Four chips "7 días" · "30 días" (default) · "90 días" · "365 días"; the chosen one is pressed (`aria-pressed`). Changing it re-renders the change lines in place; the URL keeps `?periodo=` |
| Invalid period | A URL with any other value renders the 30-day view with the notice "Elige un período de 7, 30, 90 o 365 días." above the chips (`InvalidValuationPeriod`) |

### Section: Value Summary

**OBJECT ID:** `val-value-summary`

| Property | Value |
|----------|-------|
| Component | `valuation-summary` |
| As of | "Valor al {dia}" (the valuation date, `America/Bogota`) |
| Total | `totalCop`, e.g. "$1.310.500" |
| Change | Up: "▲ +{p} % en {n} días (desde {valor})" · down: "▼ −{p} % en {n} días (desde {valor})" · equal: "Sin cambio en {n} días (desde {valor})". `{valor}` is `referencePriceAtStart` |
| Zero baseline | When `changePercent` is null (`ValuationNoBaseline`): "+{valor} · Nuevo en este período", then "Nuevo en este período: no había cartas valoradas al inicio, así que mostramos el cambio en pesos." |
| Market-only line | "Solo precios, sin las cartas nuevas: ▲ +{p} % ({valor inicial} → {valor final})"; null market baseline: "Ninguna carta estuvo en tu colección durante todo el período." |
| Coverage | "Valoradas {n} de {total} · {m} con precio desactualizado"; the "· {m}…" part is dropped when `staleCount` is 0 |
| Trend note | "Lo que valían tus cartas actuales: si quitas una carta, también sale del cálculo de fechas anteriores." |
| History | "Ver historial" → 10.2 with the same collection and period |

### Section: Not Valued

**OBJECT ID:** `val-not-valued`

| Property | Value |
|----------|-------|
| Disclosure | "No valoradas ({n})", collapsed by default; open by default when nothing is valued. Hidden when `notValued` is empty |
| Groups | One group per reason, with the reason stated once at the top: "Agregadas por enlace ({n})" → "Agregada por enlace: no tiene precio de catálogo." · "Sin precio de referencia ({n})" → "Aún no hay precio de referencia para esta carta." |
| Rows | Link-added: title · domain (external link, new tab). Unpriced: card name → 2.2 · set · "×{n}" |
| Paging | 20 rows per group, "Ver más" appends the next 20 |

### Section: Per-Card Breakdown

**OBJECT ID:** `val-breakdown`

| Property | Value |
|----------|-------|
| Disclosure | "Ver detalle por carta", collapsed by default |
| Component | `data-table` ≥768 px; stacked rows below that |
| Columns | Carta · Cantidad · Precio unitario · Valor. Numeric columns right-aligned, tabular figures |
| Stale row | Under the card name: `stale-label` "◷ Precio del {dia}: el feed no se actualiza desde entonces." The row stays in the total |
| USD line | When the reference price came from USD: `usd-line` "US${usd} · TRM al {dia}" under the unit price, as information only. Never summed, never in a total |
| Filter | "Todas" · "Con precio desactualizado ({m})" |
| Sort | "Valor" descending (default) · "Carta" A–Z; ties by entry id |
| Footer | "Total: {valor} ({n} cartas valoradas)", equal to the headline total |
| Paging | 20 rows, "Ver más" appends the next 20; the footer total is always the whole collection's |

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Loading | First load or collection change | `skeleton` total, two lines and 5 rows | — |
| No collections | Nothing added yet | "Aún no tienes colecciones para valorar." | Agregar carta |
| Empty collection | The selected collection has no entries | "Esta colección está vacía: agrega cartas para ver su valor." | Agregar carta |
| Nothing valued | Entries exist, none priced | "$0", "Valoradas 0 de {n}", the line "Ninguna carta de esta colección tiene precio de catálogo todavía.", "No valoradas" open; change per the zero-baseline rule | — |
| Default | Valued entries | As in the layout | Period, collection, disclosures, Ver historial |
| Invalid period | `InvalidValuationPeriod` | Notice above the chips; 30-day view | Choose a chip |
| Not available | `CollectionNotFound` (unknown, foreign or deleted id) | Not-available page: "No encontramos esta colección en tu cuenta." | Ver mis colecciones |
| Error — network | Load failed | §10 load copy ("…cargar el valor de tu colección…") | Reintentar |

## Technical Notes

- One call returns `{ totalCop, valuedCount, notValued[], staleCount, asOf, conversionDriftBoundCop }` plus the trend for the chosen period (FR-VAL-1, FR-VAL-2); NFR-VAL-2 budget: p95 ≤ 1.500 ms for 500 entries.
- `changePercent` and `marketChangePercent` arrive as integer hundredths (e.g. 569) or null; the browser only inserts the decimal comma. The browser never divides or multiplies money (NFR-VAL-3).
- `conversionDriftBoundCop` is not shown to collectors; it is reported on 10.3.
- The USD line comes from the catalog's price provenance for that card; the type system keeps it out of every COP sum (FR-VAL-5).
- The "Valor" sort key on 9.1 reads the same per-entry values.
