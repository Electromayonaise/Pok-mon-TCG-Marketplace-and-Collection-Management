## Overview

**Page Purpose:** Show the cards the collector wants, each with its current availability and lowest price, sorted the way she chooses, with cards nobody sells always last. The page is explicit that the wishlist is not part of any collection.

**Success Criteria:**
- Sorting by price puts every unavailable card last, in a stable order.
- The "within your max price" marker appears exactly when the lowest price is at or below the maximum.
- The area filter restricts availability to nearby listings using the same area rules as 3.1.

**Entry Points:** Mi colección tab "Lista de deseos"; 2.2 "En tu lista de deseos ✓".

**Exit Points:** 2.2 (row); 3.1 ("Ver en Cerca de ti" when the area filter is on); 9.1 and 10.1 (tabs).

## Page Sections

### Section: Controls

**OBJECT ID:** `col-wish-controls`

| Property | Value |
|----------|-------|
| Count and separation | "{n} cartas · Tu lista de deseos no cuenta como parte de tu colección." |
| Sort | "Precio más bajo" (default) · "Más disponibles" · "Agregadas recientemente". In every sort, unavailable cards go last, then by entry id |
| Area | Checkbox "Solo cerca de {ciudad} ({n} km)" using the person's saved area from 3.1; with no saved area the control reads "Elegir zona" and opens `location-picker` inline |

### Section: Wishlist Rows

**OBJECT ID:** `col-wish-rows`

| Property | Value |
|----------|-------|
| Content | Card image · name · set · availability line "Desde {precio} · {n} disponibles" or "Sin publicaciones disponibles" · the note if any |
| Marker | "✓ Dentro de tu precio máximo ({máximo})" when `lowestPriceCop ≤ maxPriceCop`; with a maximum but above it: "Tu precio máximo: {máximo}" (plain, no warning tone) |
| Row link | → 2.2, whose listings block leads to 6.1, 12.1 or 8.1 |
| Edit | "Editar" opens the row inline: "Precio máximo (opcional)" (integer COP) and "Nota (opcional)"; "Guardar" / "Cancelar" |
| Remove | "Quitar": no dialog (the wishlist is easy to rebuild); the row goes and the live region says "Quitaste {carta} de tu lista de deseos." |
| Paging | 20 rows, "Ver más" appends the next 20 |

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Loading | First load | 5 `skeleton` rows | — |
| Empty | No wishlist entries | "Tu lista de deseos está vacía. Agrega cartas desde el catálogo." | Explorar el catálogo |
| Zero results | Area filter on and nothing nearby | Rows remain, all showing "Sin publicaciones disponibles cerca"; a line above: "Ninguna carta de tu lista está a la venta en esta zona." | Quitar filtro de zona |
| Default | Rows present | As in the layout | Sort, area, edit, remove |
| Error — availability | Listings availability unavailable | Rows show without prices; notice "No pudimos cargar la disponibilidad en este momento." | Reintentar |
| Error — network | Load failed | §10 load copy ("…cargar tu lista de deseos…") | Reintentar |

---

## Technical Notes

- Availability and lowest price come from `listings.getAvailabilitySummary` (optionally area-restricted); the wishlist never reads listings tables.
- Adding a wishlist entry never creates a collection entry, and removing one never touches a collection (FR-COL-6).
- One entry per catalog card per person: adding the same card from 2.2 again updates nothing and 2.2 simply shows "En tu lista de deseos ✓".
