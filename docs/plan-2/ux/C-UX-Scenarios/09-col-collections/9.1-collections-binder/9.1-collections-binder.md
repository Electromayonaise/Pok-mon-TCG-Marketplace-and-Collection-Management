## Overview

**Page Purpose:** List the collector's named collections and show one of them as a binder: a `rows × cols` page of pockets in a stable order, with the source of every entry in words and, when filtered to one set, the set's completion.

**Success Criteria:**
- The same collection, layout and sort render the same pages every time (final tie-break: entry id).
- Every pocket says how the card got there ("Comprado en TEZG", "Agregado a mano", "Agregado por enlace · {dominio}").
- Completion is shown only with a one-set filter and never exceeds 100 %.

**Entry Points:** Mi colección root (tab Colecciones); 9.2 after adding; 9.4 "Ver en tu colección"; 10.1 back link.

**Exit Points:** 9.2 ("Agregar carta"); 9.3 and 10.1 (tabs); 2.2 (a catalog pocket's detail); 6.2 (the order link on a "Comprado en TEZG" entry); the external link of a link-added entry (new tab).

## Page Sections

### Section: Collections List

**OBJECT ID:** `col-list`

| Property | Value |
|----------|-------|
| Rows | Name · entry count ("120 cartas") · last updated. Row → the binder |
| First use | A "General" collection is created the first time the person adds anything; the list is never shown empty once any entry exists |
| New collection | "Nueva colección": inline name field (1–60 characters) + "Crear". `CollectionNameTaken` shows as `field-error` under the field: "Ya tienes una colección llamada «{nombre}». Elige otro nombre." Success: the new row appears, focused, and the live region says "Creaste la colección «{nombre}»." |
| Limit | At 50 collections the field is replaced by the §8 limit line |

### Section: Binder Toolbar

**OBJECT ID:** `col-binder-toolbar`

| Property | Value |
|----------|-------|
| Organizar | Opens an inline panel (not a modal): "Filas" 1–5 and "Columnas" 1–5 (default 3×3); up to 3 sort keys from Fecha de adquisición · Valor · Set · Número · Pokémon · Artista · Color · Manual, each "Ascendente" or "Descendente"; "Guardar". Saved per collection |
| Filter | "Filtrar por set" (one set). Only this filter shows completion |
| Opciones | "Cambiar nombre" (inline field, same rules as creation) · "Eliminar colección" (`<dialog>`, see Delete) |
| Add | "Agregar carta" → 9.2 with this collection preselected |

### Section: Binder Page

**OBJECT ID:** `col-binder-page`

| Property | Value |
|----------|-------|
| Component | `binder-grid`; page size = rows × cols; empty pockets on the last page are dashed outlines, never placeholder art |
| Pocket content | Image (catalog image, or the link's `imageUrl` loaded in the browser with `referrerpolicy="no-referrer"`; none → a plain pocket with the title) · name · condition if recorded · "×{n}" when qty > 1 · `source-badge` |
| Source badge | "Comprado en TEZG" (with "Ver pedido" → 6.2) · "Agregado a mano" · "Agregado por enlace · {dominio}" |
| Order | The saved sort keys, then entry id ascending. For catalog-attribute keys, link-added entries go after catalog entries, sorted by title. Sort key "Valor" reads VAL's per-entry value; unvalued entries sort last |
| Pocket menu | "Mover a…" · "Copiar a…" (a list of the owner's other collections) · "Editar" (qty, date, price paid) · "Quitar" |
| Move / copy result | The page re-renders; the live region says "Movida a «{colección}»." or "Copiada a «{colección}»." A copy keeps source, order link, quantity and acquisition date |
| Manual order | With sort key Manual: drag a pocket, or select it and use "Mover antes / después", or arrow keys with Space to pick up and drop. Live region: "{carta} movida a la posición {n} de {total}" |

### Section: Binder Footer

**OBJECT ID:** `col-binder-footer`

| Property | Value |
|----------|-------|
| Paging | "‹ Anterior" · "Página {n} de {total}" · "Siguiente ›"; the page number is in the URL (`?pagina=2`) so a link reopens the same page |
| Completion | Only with a one-set filter: "· {a}/{b} ({p} %)". `{a}` = distinct catalog cards of that set owned in this collection; `{b}` = all catalog cards of that set, secret rares included; sealed products and link-added entries never count; `{p}` rounded down |
| Mobile, ≥ 4 columns | Same page contents, shown as a horizontally paged view (swipe or the same buttons), never a scrolled strip |

### Section: Delete Collection

**OBJECT ID:** `col-delete`

| Property | Value |
|----------|-------|
| Dialog | `<dialog>`: "Se eliminará «{nombre}» y sus {n} cartas. Esto no se puede deshacer." + `button-destructive` "Eliminar colección" + "Cancelar" |
| After | Back to the collections list; live region "Eliminaste «{nombre}»." |

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Loading | Page or binder loading | `skeleton` pockets in the saved layout | — |
| No collections | New account, nothing added yet | "Aún no tienes colecciones. Agrega tu primera carta y la guardaremos en «General»." | Agregar carta |
| Empty collection | No entries | "Esta colección está vacía. Agrega tu primera carta." | Agregar carta |
| Zero results | The set filter matches nothing | "No tienes cartas del set {set} en esta colección." | Quitar filtro |
| Default | Entries present | As in the layout | All toolbar actions |
| Entry gone | `CollectionEntryNotFound` on move, copy, edit or remove (e.g. removed in another tab) | Notice banner "Esta carta ya no está en tu colección. Actualizamos la vista." and the page re-renders | — |
| Not available | `CollectionNotFound` (unknown, foreign or deleted id) | Not-available page: "No encontramos esta colección en tu cuenta." | Ver mis colecciones |
| Error — network | Load failed | §10 load copy ("…cargar tu colección…") | Reintentar |
| Error — command | Move, copy, reorder or delete not confirmed | §10 command-not-confirmed copy | Actualizar |

## Technical Notes

- Page content is computed server-side from the saved layout and sort with the entry-id tie-break, so two renders of the same page are identical (FR-COL-5 acceptance: 120 entries, 3×3, set then Pokémon → 14 pages, the 2 link entries on the last page).
- The completion denominator counts `kind=card` catalog entries of the set from the catalog, not the printed card count.
- Foreign and unknown ids return the same "not found" so the page never reveals that another person's collection exists.
- The binder never fetches a link-added entry's URL server-side (FR-COL-3); the image request is made by the browser only.
