## Overview

**Page Purpose:** Add one entry to a collection, either a catalog card found by search or a card outside the catalog given by link, with quantity, acquisition date and an optional price paid. Entries added here are always "Agregado a mano"; only the post-purchase prompt creates "Comprado en TEZG" entries.

**Success Criteria:**
- A link entry is saved with title, link and optional image, and TEZG never opens the link.
- Every field error is shown in place and nothing typed is lost.
- After saving, the person lands on the binder page that holds the new entry.

**Entry Points:** 9.1 "Agregar carta" (collection preselected); 2.2 "Agregar a mi colección" (tab Del catálogo, card preselected, collection = most recently used).

**Exit Points:** 9.1 (saved, or "Cancelar").

## Page Sections

### Section: From the Catalog

**OBJECT ID:** `col-add-catalog`

| Property | Value |
|----------|-------|
| Search | Catalog search by name or set number; results show image, set and number; choosing one fills the card block |
| Rule | The card must be a catalog entry that resolves; if it was merged or removed meanwhile, the card block shows `field-error` "Esta carta ya no está en el catálogo. Búscala de nuevo." |
| Duplicates | Allowed: the same card can have several entries (e.g. different acquisition dates) |

### Section: By Link

**OBJECT ID:** `col-add-link`

| Property | Value |
|----------|-------|
| Enlace de la carta | `type="url"`, https only, ≤ 2.048 characters. Error: "El enlace debe empezar por https:// y tener menos de 2.048 caracteres." |
| Nombre de la carta | 1–120 characters. Error: "Escribe un nombre para la carta (hasta 120 caracteres)." |
| Enlace de la imagen | Optional, https only. Error: "El enlace de la imagen también debe empezar por https://." A preview loads in the browser only after the field is valid |
| Note | "TEZG no abre este enlace: solo guardamos el nombre, el enlace y la imagen que indiques." |
| Server check | The server repeats every rule and returns `InvalidExternalLink` citing the failing field; the page maps it to the same in-place error |

### Section: Common Fields and Save

**OBJECT ID:** `col-add-common`

| Property | Value |
|----------|-------|
| Colección | Select of the owner's collections; preselected from the entry point |
| Cantidad | Integer 1–999, default 1. Error: "La cantidad debe estar entre 1 y 999." |
| Fecha de adquisición | Date, default today (`America/Bogota`). Error: "La fecha no puede ser posterior a hoy." |
| Precio pagado | Optional integer COP 0–100.000.000. Error: "El precio debe estar entre $0 y $100.000.000." |
| Save | "Agregar a «{colección}»" (`button-primary`). Several errors → the error summary at the top lists each as an in-page link, and focus moves there |
| Success | Navigate to 9.1 on the page holding the new entry, which is briefly outlined; live region "Agregaste {carta} a «{colección}»." |

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Loading | Collections list loading | `skeleton` form | — |
| Empty — no collection yet | Reached from the 9.1 empty state ("Agregar carta") on an account with no collection | The collection select has one option, «General (se creará al guardar)». The first save creates it (FR-COL-1 "created on first use"). The route has no collection id in this case; Phase 3 fixes its exact form | Agregar |
| Default | Tab chosen | As in the layout | Agregar, Cancelar |
| Field errors | Client or server validation | In-place `field-error` + summary; values kept | Fix and resend |
| Collection gone | `CollectionNotFound` on save (deleted in another tab) | Refusal banner "No encontramos esta colección en tu cuenta." with the select reopened. If no collection remains, the select offers «General (se creará al guardar)» | Elegir otra colección |
| Error — network | Save not confirmed | §10 command-not-confirmed copy ({acción} = "la carta") | Actualizar |

## Technical Notes

- `source` is always `Manual` on this page; the UI has no control for it.
- The link and image are stored as given; there is no server-side fetch, unfurl or thumbnail (FR-COL-3). No `CatalogEntry` is created.
- Double submit: the button shows "Agregando…" and ignores further activations until the response arrives.
