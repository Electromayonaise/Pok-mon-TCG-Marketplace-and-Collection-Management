## Overview

**Page Purpose:** Show every listing the seller owns, in its §8 state, with the reason in words. Surface shared inventory, and offer edit, restock and deactivate within the rules (FR-INV-4, FR-INV-7..10).

**Success Criteria:**
- Each row's state label matches the §8 glossary and cites its cause.
- Shared-unit siblings are visible.
- No action is offered that the state forbids. Instead, the reason is shown.

**Entry Points:** Account menu → Mis publicaciones / Mi tienda; the 4.1 success redirect; the COM balance banner; the VER status page.

**Exit Points:** 4.1 (new); the edit sheet (in place); 7.1 (Recargar saldo); 5.2 (Ver estado de la solicitud); 2.2 (Ver como comprador).

## Page Sections

### Section: Seller Status Banner

**OBJECT ID:** `inv-mine-banner`

| Property | Value |
|----------|-------|
| Component | `explainability-banner`; at most one, by priority: Withdrawn (rejected) > Paused (balance) > Unverified (pending) |
| Copy | From microcopy §3 owner rows (tú). Actions: "Ver estado de la solicitud" / "Recargar saldo" |
| Business header | `verification-status-badge` plus, when Approved, a compact `commission-balance-card` ("Saldo: $42.000 COP") linking to 7.1 |

### Section: State Filter

**OBJECT ID:** `inv-mine-filter`

| Property | Value |
|----------|-------|
| Component | Chip tabs with counts: Todas · Activas · Sin verificar · Pausadas · Agotadas · Desactivadas · Retiradas · Ocultas. Chips with 0 are hidden, except "Todas" |

### Section: Listing Rows

**OBJECT ID:** `inv-mine-rows`

| Property | Value |
|----------|-------|
| Component | `listing-card` owner variant |
| State → label → actions | **Activa**: Editar, Reponer, Desactivar. **Sin verificar**: label per microcopy; Editar, Reponer, Desactivar. **Pausada**: "Pausada: se reactivará cuando recargues tu saldo"; Editar, Reponer, Desactivar. **Agotada**: Editar, Reponer. **Desactivada**: "Desactivada por ti"; Reactivar, Editar. **Retirada**: Withdrawn copy; Ver (read-only). **Oculta**: Hidden copy with reason and note; Contactar a soporte |
| Shared inventory | When a unit backs more than one listing: "⇄ Comparte inventario con {n} publicación(es) más ({títulos})". Tapping expands the sibling list with each sibling's availability |
| Sold out cause | When availability reached 0 through a sibling: "({carta} se reservó en otra publicación)" (covers purchases and accepted trades) |
| Individual rows | Never show purchasable or paused states. The `openToTrade` badge "Abierta a intercambios" is shown when on |

### Section: Edit & Restock Sheet

**OBJECT ID:** `inv-mine-edit`

| Property | Value |
|----------|-------|
| Edit | Price, description, location, and openToTrade (individual only). The note "Cambiar el precio no afecta pedidos ni ofertas ya hechos." |
| Restock | Signed stepper "Ajustar inventario: −/+" showing the current unit quantity and the listings affected. Negative beyond 0: "No puedes bajar el inventario por debajo de 0: hay {disponibles} unidades." (`InsufficientQuantity`) |
| Reactivate refused | Withdrawn or hidden: "No puedes reactivarla mientras esté {retirada / oculta por moderación}." |

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Loading | Fetch | Banner skeleton plus 3 row skeletons | — |
| Empty | No listings | `empty-state` "Aún no tienes publicaciones." | Nueva publicación |
| Error | Fetch failed | Banner plus Reintentar | Reintentar |
| Success | Rows | As in the layout | Row actions |
| Lost race (edit) | Save conflicts with a concurrent sale (restock negative now fails) | Inline `field-error` with the fresh quantity; the sheet stays open | Ajustar |

---

## Technical Notes

- States are derived on read (FR-INV-7, FR-IDN-6). The badge is never cached. The page re-fetches on focus after more than 60 s.
- A dual-role account (IDN-S1) sees only its own seller kind's listings here; purchases are under "Mis pedidos" (6.2).
- Ids are never shown; titles come from the catalog.
