## Technical Notes

- No loading or error state exists for this page on its intended entry path — it is only ever navigated to on a confirmed-successful publish response from 1.2; there is nothing left to fetch or fail there.
- If Valentina reaches this page a second time via browser back-navigation after the listing's state has since changed (e.g. it sold or was removed), the listing-card refetches on mount rather than rendering the cached publish-time snapshot — so a stale "your listing is live" confirmation is never shown for a listing that's no longer actually active.
