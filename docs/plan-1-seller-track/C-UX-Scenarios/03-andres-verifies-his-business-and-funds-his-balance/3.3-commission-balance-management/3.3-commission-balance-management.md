## Overview

**Page Purpose:** Let Andrés view and top up his prepaid commission balance, and create or continue creating business listings by reusing 1.2's shared form (FR-S6, FR-S9, CAP-21) — a convenience shortcut available here since he's already Approved, not the only path to listing creation (that path opens as soon as his application exists, per 3.2).

**User Situation:** Freshly approved, he lands here from 3.2 whether or not he's already created a listing while Pending. Later, he returns here whenever his balance runs low.

**Success Criteria:** Balance state (Funded/Zero-paused) is always clear; top-up works; listing creation is always reachable from here once Approved, regardless of balance — only purchasability is balance-gated (FR-S6).

**Entry Points:**
- 3.2, "Continue to your balance" (first visit, Approved).
- Account menu → "Commission balance" (return visits).

**Exit Points:**
- → 1.2 Create Listing (via "Create a listing," `sellerType=business`) — always reachable regardless of Funded/Paused state (FR-S9).
- Stays on page after a top-up.
- Returns here after a successful publish from 1.2 (`sellerType=business`), showing the Listing Published Banner.

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Funded | Balance > 0 | Green/positive status, Create a Listing enabled | Top up, create a listing |
| Zero — Paused | Balance = 0 | Paused status, existing listings noted as hidden (not deleted), Create a Listing still enabled (FR-S9) | Top up, create a listing |
| Just published | Returned here right after a successful business-side publish | Listing Published Banner visible above the balance card | Dismiss (or auto-dismisses) |
| Top-up in progress | Top-up submitted (modal) | Modal's submit control disabled | None |
| Top-up error | Top-up fails | Inline error inside the modal: "Couldn't process your top-up — check your connection and try again" | Retry |
| Loading | Page opens | Skeleton card | — |

## Technical Notes

- This page never offers a manual "resume selling" action — the Funded/Paused transition is automatic on balance crossing zero in either direction, per CAP-21's explicit no-manual-resume criterion.
- Pausing at zero balance never deletes or archives existing listings — they remain in Andrés's inventory, simply non-purchasable to buyers, and become purchasable again automatically the moment the balance is topped up.
- The reused `create-listing-form` (see [1.2](../../01-valentina-publishes-her-first-listing/1.2-create-listing/1.2-create-listing.md)) renders with `sellerType=business`, which structurally omits the `open-to-trade-toggle` per AD-4 — this page does not duplicate that form's spec, only its entry point.
- Publishing is never rejected for balance reasons, including a balance that crosses zero between opening 1.2 and submitting (e.g. a concurrent commission deduction on another Order) — FR-S9 is explicit that creation is never balance-gated, only purchasability is (FR-S6). CAP-21's pause-without-recreation invariant governs the resulting listing's visibility to buyers, not whether the publish itself succeeds.
