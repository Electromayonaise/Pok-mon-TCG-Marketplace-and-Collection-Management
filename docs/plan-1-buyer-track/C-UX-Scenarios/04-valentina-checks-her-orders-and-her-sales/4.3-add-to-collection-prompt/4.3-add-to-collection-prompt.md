## Overview

**Page Purpose:** Offer a dismissible prompt to add the purchased item to a collection — never created automatically (FR-8, CAP-27).

**User Situation:** Appears immediately after confirming item-received on 4.2.

**Success Criteria:** Accepting creates a collection entry tagged `source=PlatformPurchase`; declining or ignoring creates no entry, and the Order's closed status is unaffected either way (FR-8's testable Consequence).

**Entry Points:**
- ← 4.2 Order Detail (auto-appears immediately after item-received confirmation).

**Exit Points:**
- → 4.4 My Sales Tab (after accepting or declining).

## Page Sections

### Add-to-Collection Modal

**OBJECT ID:** `add-to-collection-modal`

| Property | Value |
|----------|-------|
| Content | Card thumbnail + name, `{components.button-primary}` "Add to Collection," secondary text link "Not now" |
| Behavior | Accepting creates a collection entry tagged `source=PlatformPurchase` and navigates to 4.4. Declining (any of the three dismiss methods) creates no entry and navigates to 4.4 identically — the Order's already-closed status is unaffected by either choice (FR-8's testable Consequence) |

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default | Modal opens | Full prompt as above | Add to Collection, or dismiss |
| Adding | "Add to Collection" tapped | Button disabled briefly (double-submission guard) | None |
| Error | Add-to-collection request fails | Inline error within the modal: "Couldn't add this to your collection — try again" | Retry, or dismiss anyway (the Order is unaffected regardless) |
