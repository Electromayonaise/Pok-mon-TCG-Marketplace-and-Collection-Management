## Overview

**Page Purpose:** See listing price, last-transaction reference price, and historical trend as three distinct, clearly labeled values (FR-3, CAP-3) — the scenario's climax and TEZG's single highest-leverage surface per the Trigger Map's Design Focus Statement.

**User Situation:** Just tapped a card from the filtered catalog; this is the moment she decides whether to trust TEZG's price at all.

**Success Criteria:** Trusts the price display enough to keep browsing instead of switching to an external app (eBay/PriceCharting/Collectr). Continues into Scenario 02 in the same session.

**Entry Points:**
- ← 1.2 Catalog Browse & Filter (tapping any tile, including zero-listing ones).

**Exit Points:**
- → 2.1 Listing Search Results & Comparison (tapping "Compare Listings," only when `hasActiveListings=true`).

## Page Sections

### Card Hero

**OBJECT ID:** `card-detail-hero`

| Property | Value |
|----------|-------|
| Content | Full card art, card name, set name + collector number |

### Price Block

**OBJECT ID:** `card-detail-price-block`

| Property | Value |
|----------|-------|
| Component | [`{components.price-block}`](../../../DESIGN.md) — 3 rows |
| Row 1 | "Listing price" — the lowest current active listing price, COP |
| Row 2 | "Reference price" — last-transaction price, shown as its COP-converted equivalent only (Phase 3A Key Decision: never raw USD, so the two figures stay directly comparable) |
| Row 3 | "Trend (30d)" — `changePercent` over the period, rendered as a **signed** figure with a directional glyph (`▲`/`▼`) AND the `+`/`-` sign together with `colors.trend-positive`/`trend-negative` — color is never the only signal (closes the Phase 3A Reviewer Gate finding on trend-direction accessibility) |
| Behavior | All three rows always render with their label visible — never collapse into a single unlabeled number (FR-3's testable Consequence) |

### Compare Listings CTA

**OBJECT ID:** `card-detail-compare-button`

| Property | Value |
|----------|-------|
| Component | `{components.button-primary}` |
| Content | "Compare Listings" |
| Behavior | Only rendered when `hasActiveListings=true`; navigates to 2.1 scoped to this card |

### Empty State (zero active listings)

**OBJECT ID:** `card-detail-empty-state`

| Property | Value |
|----------|-------|
| Component | `{components.empty-state}` — this is the correct, sole location for this pattern per the Phase 3A Reviewer Gate correction (not 1.2's individual tiles) |
| Content | "No active listings for this card right now" |
| Behavior | Replaces the price-block's listing-price row context and the Compare button; reference price and trend rows still render above it, since those two values don't depend on an active listing existing |

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default (has listings) | `hasActiveListings=true` | Full 3-row price-block, Compare Listings enabled | Tap Compare Listings |
| Empty (no listings) | `hasActiveListings=false` | Reference price + trend rows render; `card-detail-empty-state` in place of listing price + CTA | Navigate back to catalog; no purchase path from here |
| Loading | Data still resolving | Skeleton block matching the price-block's row layout (no layout shift on resolve) | None |

---

## Technical Notes

- Historical trend renders as a `period` / `changePercent` / `referencePriceAtStart` delta, not a full time-series chart — keeps this page's job to a single glanceable trust signal, not an analytics view.
- The three price-block values must remain visually distinguished by label (not color alone) for colorblind users — accessibility floor requirement, already satisfied by the always-visible row labels.
