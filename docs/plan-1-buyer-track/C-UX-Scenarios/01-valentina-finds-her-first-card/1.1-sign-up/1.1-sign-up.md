## Overview

**Page Purpose:** Create an account with no onboarding step blocking access to the catalog (FR-1).

**User Situation:** New to TEZG, tired of juggling eBay, PriceCharting, and Collectr. Arrives via a friend's referral link on her phone, between sets at a release event.

**Success Criteria:** Account created, session started, Valentina lands directly on the catalog — no interstitial profile/preferences step.

**Entry Points:**
- Friend's referral link (unauthenticated, mobile browser).

**Exit Points:**
- → 1.2 Catalog Browse & Filter (on successful account creation).

## Layout Structure

Single centered column, no side navigation (unauthenticated). Vertically stacked: wordmark, heading, form, footer link.

```
+--------------------------------+
|            TEZG                |
|                                 |
|      Create your account       |
|                                 |
|  [ Email                    ]  |
|  [ Password                 ]  |
|                                 |
|  [     Create Account       ]  |
|                                 |
|   Already have an account?     |
|          Sign in               |
+--------------------------------+
```

Widens only to a wider centered column at tablet/desktop (max ~400px) — never a two-column layout; this page has one job.

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default | Page loads, no input yet | Empty fields, button enabled once both fields are non-empty and pass client-side format checks | Fill fields, submit |
| Validating | Field loses focus | Inline error on that field only if invalid (per Voice and Tone copy) | Correct and retry |
| Submitting | Submit tapped | `signup-submit-button` disabled, label unchanged (no separate loading label needed — round trip is fast) | None (guard against double-submit) |
| Error — duplicate email | Server rejects: email already registered | Inline error under email field: "That email's already registered — try signing in instead" | Edit email, or tap Sign In link |
| Error — weak password | Server rejects: password policy | Inline error under password field: "Choose a password with at least 8 characters" | Edit password, retry |
| Error — network/server failure | Request fails to complete | Inline error above the form: "Couldn't create your account — check your connection and try again" | Retry |
| Success | Account created | Brief transition, navigates to 1.2 | — |

---

## Technical Notes

- No CAPTCHA, no email-verification gate before catalog access — FR-1's testable Consequence is "no additional onboarding step blocking access," and inserting a verification wait would violate it. Email verification, if added later, must not block the 1.1 → 1.2 transition.
- This page has no "remember me" / social-login options in scope — out of this track's 4 scenarios; Better Auth's session cookie (`userId`) is issued on successful creation per the whole-system architecture invariant.
