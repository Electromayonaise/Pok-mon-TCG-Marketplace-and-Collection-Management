# Solu-1 schemas — migrations and DTOs

**Phase 2.2.** The SQL files in this folder are the authoritative DDL (decision log #11). They are applied in file order to PostgreSQL 16 by the test harness, and later become Prisma migration SQL. Verified on `postgres:16.6`: all 12 files apply cleanly and create 33 tables.

```bash
npm run db:up            # docker compose, port 55432
for f in docs/solu-1/planning/schemas/*.sql; do
  docker compose exec -T postgres psql -v ON_ERROR_STOP=1 -U tezg -d tezg < "$f"
done
```

## Conventions (decision log #9)

| Template element | Solu-1 form | Why |
|---|---|---|
| `id UUID PRIMARY KEY DEFAULT gen_random_uuid()` | `id TEXT PRIMARY KEY CHECK (tezg_is_cuid(id))`, generated by the `IdGenerator` port | `project-context.md`: cuid2 ids everywhere; the CHECK keeps the id physically well-formed |
| `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()` | `"createdAt" TIMESTAMPTZ NOT NULL`, no default; append-only logs use `at` | AD-SYS-6: time comes only from `Clock`. A forgotten value fails `NOT NULL` instead of silently taking wall-clock time |
| `snake_case` names | `"PascalCase"` tables, `"camelCase"` columns | Plan-2 Prisma models (ARCH §6) |
| Cross-table FKs | Only within one host module | AD-8 table ownership; each module stays independently testable |

## Invariants enforced physically

Each row is a constraint the database refuses to violate, whatever the application code does.

| # | Invariant | Constraint | AD |
|---|---|---|---|
| P-1 | A seller is individual **or** business, never both, and never switches | composite FKs `individual_profile_user_track_fk`, `business_application_user_track_fk` → `User(id, "sellerTrack")` `ON UPDATE RESTRICT` | AD-IDN-2, AD-18 |
| P-2 | One pending application per business | partial unique `business_application_one_pending` | AD-VER-3 |
| P-3 | Pending ⇔ undecided; a rejection snapshots its policy | `business_application_pending_iff_undecided`, `business_application_rejection_snapshot` | AD-VER-1 |
| P-4 | At most one running feed run | partial unique `feed_run_single_running` | AD-CAT-1 r1 |
| P-5 | One `externalKey` ⇔ one catalog id | `UNIQUE ("externalKey")` | AD-CAT-1 r5, AD-7 |
| P-6 | Stock never negative; one pool per (seller, item, condition) | `CHECK (quantity >= 0)`, `inventory_unit_one_pool` | AD-6, AD-INV-1 |
| P-7 | Only individual-seller listings open to trade; individuals never paused | `listing_trade_individual_only`, `listing_individual_never_paused` | AD-4, AD-INV-3 r6 |
| P-8 | A sealed product is never a bundle component | `BundleComponent.condition` excludes `Sealed` | AD-INV-1 r5 |
| P-9 | "Paid" requires a comprobante; facts are ordered; paid never expires | `order_paid_requires_comprobante`, `order_seller_after_paid`, `order_item_after_paid`, `order_paid_never_terminated` | AD-2, AD-ORD-2 |
| P-10 | Order total is exact | `order_total_exact` | AD-SYS-7 |
| P-11 | One deduction per order | partial unique `ledger_one_deduction_per_order` | AD-COM-2, AD-SYS-3 |
| P-12 | The charged amount is the rounding rule | `ledger_deduction_rounding_rule`: `amountCop = (baseCop × rateBps + 5000) / 10000` | ADD-§2.6, AD-COM-2 r1 |
| P-13 | Account state is a function of the balance | `commission_account_state_matches_balance` | AD-COM-1 |
| P-14 | One live offer per proposer and listing | partial unique `trade_offer_one_open_per_proposer` | AD-TRD-1 r6 |
| P-15 | Only accepted or cancelled offers hold a reservation | `trade_offer_reservation_states`, `trade_offer_accepted_has_reservation` | AD-TRD-3 |
| P-16 | One conversation per pair; seq unique; idempotent send | `conversation_one_per_pair`, `message_seq_unique`, `message_idempotent_send` | AD-MSG-2 |
| P-17 | Tagged-union entries; purchase entries name their order | `collection_entry_catalog_tag`, `collection_entry_source_order` | AD-7, AD-COL-1 |
| P-18 | One prompt per closed order | `UNIQUE "PostPurchasePrompt"."orderId"` | AD-COL-2 r1 |
| P-19 | A business review is purchase-verified; an individual one is not | `review_business_iff_verified` | AD-REP-1 r2 |
| P-20 | Append-only tables cannot be edited; reviews and listings cannot be deleted | `099_grants_append_only.sql` (+ default privileges, review E-18) | AD-SYS-8 r10, AD-12 |
| P-21 | One account per mailbox, case-insensitive | unique index `user_email_case_insensitive` (review E-01) | AD-IDN-2 |
| P-22 | A listing or bundle sells only its own seller's units; component attributes match the unit | `listing_unit_same_seller`, `bundle_component_listing_seller`, `bundle_component_unit_matches` (review E-05, E-06) | AD-6, AD-INV-1 |
| P-23 | Order facts are ordered in time; the comprobante precedes "paid"; a reason exists only on a terminated order | `order_seller_not_before_paid`, `order_item_not_before_paid`, `order_comprobante_not_after_paid`, `order_reason_iff_terminated` (review E-07, E-08) | AD-2, AD-ORD-2 |
| P-24 | Only a participant writes in a conversation; bodies are NFC | `message_sender_is_participant`, `body IS NFC NORMALIZED` (review E-12, E-13) | AD-MSG-2, FR-MSG-5 |
| P-25 | Hide reasons come from the policy list | `hiddenReason` CHECKs on `Listing`, `Review` (review E-17) | AD-12, ADD-§9.2 |
